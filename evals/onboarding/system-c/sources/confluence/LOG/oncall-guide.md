# LOG-L2 on-call guide

Start in Grafana (`grafana.logistics.acme.internal`): the Shipment Tracking dashboard shows
request rates, event-loop lag per service, queue depths and MongoDB slow operations.
Escalate carrier outages to the FastShip account manager; check their status page first.
