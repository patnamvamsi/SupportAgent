# 12. Work Packages — v0.2 SRE on live signals (re-scoped by ADR-0022)

**Release goal ([ADR-0022](../adr/0022-v0-2-sre-on-live-signals.md)):** SupportAgent works from live signals as well as tickets. It discovers a system's stack and signals, proposes reviewed detectors, triages alerts through the same gate, follows errors into the code, and proposes recovery runbooks, carrying out each step once it is approved. It is proven on a real system (the proving ground) without the core naming it: every system-specific item is the deployment's data, and every incident becomes a generic scenario on reference System D.
**Version line:** `0.2.x`. **Migrations:** from 0023.
**Depth:** work-package level with acceptance tests. The first PR of each WP refines its file list and interfaces.
