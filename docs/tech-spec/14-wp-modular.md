# 14. Work Packages: the modular framework (ADR-0011)

**Goal:** the agent triages and finds root causes with stack-specific skills, measured by the incident lab, on any incident system and any tool backend, with the trust core unchanged.
**First pack:** `python-postgres` (Python microservices and web servers on Postgres). **Placeholders:** `spark`, `snowflake`.
**Ordering:** capability first (packs, lab, tools, RCA on), then pluggability (bindings with MCP, connectors), then knowledge and analyst-authored extensions. This plan comes before the v0.2 WPs; WP-204 (MCP) is absorbed into WP-M06.
**Depth:** work-package level with acceptance tests. Each WP gets file lists and the full test list in its own PR.

## Eval operations

- **Every PR:** invariants, contracts, and the lab replayed from cached LLM responses.
- **Nightly:** the lab live on Qwen (N samples) and the scenario simulations. Both run on a self-hosted GitHub runner on the LAN host (runbook step 7).
- **Any prompt, pack or model change:** the full lab with a per-case diff against the baseline before merge.
- **Weekly:** production and shadow misses reviewed and promoted into lab scenarios.
